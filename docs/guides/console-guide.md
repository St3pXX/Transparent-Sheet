# 控制台使用指南

## 概述

Next.js 控制台是 TransparentSheet 的 Phase 1-4 主要交互界面，提供任务输入、实时执行、结果展示、确认/修改功能。

## 界面布局

```
┌──────────────────────────────────────────────────────┐
│  TransparentSheet  │  任务  历史  数据  设置  │  就绪 · v2.0  │
├──────────┬─────────────────────────────────────────┤
│          │                                          │
│  指令     │  Entry Banner                          │
│  [     ] │  ┌──────────┬──────────┬──────────┐    │
│  [     ] │  │ Review   │ Analysis │ Risk     │    │
│          │  │ AgentCard│ AgentCard│ AgentCard│    │
│ [执行任务] │  └──────────┴──────────┴──────────┘    │
│          │  Report CTA (确认/修改)                  │
│ 最近      │                                          │
│ · 进行中  │                                          │
│ · 已完成  │                                          │
└──────────┴─────────────────────────────────────────┘
```

## 操作流程

### 1. 输入任务

在左侧"指令"文本框中描述任务目标，例如：

```
补全本周销售数据并生成运营周报
```

按 `Ctrl+Enter` 或点击"执行任务"按钮。

### 2. 观察执行

各 Agent 实时输出会分轨展示在对应面板：
- **Entry Banner**：数据录入进度、新增记录数、完整率
- **Review AgentCard**：异常数据标注（REC_042/019）
- **Analysis AgentCard**：KPI 指标（销售额/订单数/客单价/复购率）、趋势图、分析洞察
- **Risk AgentCard**：高/中/低风险预警列表

### 3. 确认/修改

报告生成后，底部显示 Report CTA 卡片：
- 点击"确认写入"：系统写入飞书表格
- 点击"修改报告"：进入修改模式，调整后重新提交

## 系统状态

顶部右侧显示系统状态：
- 绿色闪烁点 + "就绪 · v2.0"：系统正常
- 蓝色"进行中"：任务执行中
- 蓝色"待确认"：报告待用户确认

## 快捷键

| 功能 | 快捷键 |
|------|--------|
| 执行任务 | Ctrl + Enter |
| 清空输入 | Ctrl + Shift + X |

## 数据流

任务通过 SSE（Server-Sent Events）实时推送，前端 Zustand store 自动更新各面板状态，无需页面刷新。
